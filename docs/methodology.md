## Журнал версий модели

Версия модели записана у каждой оценки. При смене версии сервис пересчитывает историю по
сохраненным фактам, строки прежних версий не перезаписываются.

- `4.5.0-hci`, сборщик 6 (18.10.2026): разделы установки, сборки и тестов в README находятся
  по любой форме слова в заголовке («Как запустить», «Installation», «Test», «Тестирование»),
  в том числе в заголовках, подчеркнутых строкой `===` или `---`. Формула не меняется,
  репозитории пересобираются ночной волной.
- `4.5.0-hci`, сборщик 5 (28.09.2026): открытая находка AppSec с критичностью `CRITICAL`
  ограничивает Repo Health Score значением 69 – верхом зоны «требует внимания». Утекший
  секрет по-прежнему ограничивает его значением 49, действует меньший потолок. HealthCraft
  Index, места и рейтинг не меняются: данных AppSec в индексе нет.
- `4.4.0-hci`, сборщик 5 (26.09.2026): справочные показатели без веса – стабильность CI в
  динамике, динамика создания и закрытия задач, ревью запросов на слияние и узкие места, карта
  владельцев файлов. Баллы, индекс, покрытие, места и рекомендации не меняются.
- `4.3.1-hci`, сборщик 4 (26.09.2026): пометки техдолга считаются только в коде вне тестов;
  у репозитория без кода Состояние кода получает 0 с причиной вместо «нет данных»;
  рекомендации с нулевым эффектом не выводятся.
- `4.3.0-hci`, сборщик 3 (24.09.2026): тесты как бонус, сжатие балла для малого кода и малой
  выборки задач, потолки Безопасности, CI без видимых запусков – «нет данных».
