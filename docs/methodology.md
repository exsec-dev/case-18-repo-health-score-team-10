## Журнал версий модели

Версия модели записана у каждой оценки. При смене версии сервис пересчитывает историю по
сохраненным фактам, строки прежних версий не перезаписываются.

- `4.7.0-hci`, сборщик 7 (20.10.2026): у каждой подметрики худший случай дает 0 – ненулевых
  полов у шкал больше нет. Задачи не ведутся – категория «Задачи» получает 0 вместо 6, к 0
  сжимается и балл малой выборки задач. Нет предложений изменений или релизов – 0 вместо 20.
  1 автор – 0 вместо 20, 10 и 100 авторов по-прежнему дают 60 и 100. Доля зависших задач 100%,
  доля решенных задач и закрытых находок 0% – 0 вместо 10. Новые пороги с баллом 0: 36 месяцев
  без коммитов людей, доля старых пометок 100%, 200 записей в корне, запуск CI от 60 минут,
  плотность находок от 40. Если успешных запусков CI нет, длительность получает 0, а не выпадает
  из расчета, поэтому CI без единого успешного запуска получает 30, а не 40 – меньше, чем
  медленный, но работающий CI. Полный балл Задач – только если задачи закрывали хотя бы в 3 разных
  дня: пачка задач-пустышек, закрытых за день, дает не больше трети балла; для этого сборщик 7
  записывает число дней закрытия (у фактов прежних сборщиков без него поправки нет). Релизы
  засчитываются, только если за 12 месяцев был коммит человека: иначе подметрика релизов получает 0,
  и автоматические релизы заброшенного проекта Активность не поднимают. Проверка AppSec, которая
  ни разу не запускалась, дает Безопасности 0, а не «нет данных», пока AppSec не вернет находки.
  В уязвимых зависимостях пакет, версию которого уже подняли после проверки AppSec, в сумму и
  список не входит (счетчик «обновлены»), а пакеты экосистем, которые прочитанные lock-файлы
  не описывают (все, кроме npm: Python, Rust, .NET, Ruby, Go, Maven, PHP и другие – по метке
  движка SCA), считаются вне графа: показываются, но не взвешиваются. У старых находок без метки
  экосистема определяется по форме имени: Go (`github.com/x/y`) и Maven (`group:artifact`) вне
  графа, остальные имена сопоставляются с графом. CI с неразобранным `ci.yaml` оценивается по
  запускам, а CI, у которого ни один запуск не завершился (все отменены, пропущены или идут),
  получает 30, как CI без запусков; при незнакомых статусах запусков или неразобранном `ci.yaml`
  без завершенных запусков остается «нет данных». Остальные пороги не менялись; на участках шкал между новым нулем
  и прежними порогами баллы ниже, например 2 автора дают 18 вместо 32, 4 автора – 36 вместо 44.
  На выборке из 23 тыс. репозиториев HealthCraft Index снизился в среднем на 3 балла, порядок
  рейтинга почти не изменился, около 12% репозиториев перешли из «требует внимания» в «в зоне
  риска».
- `4.6.0-hci`, сборщик 7 (20.10.2026): в Безопасности появилась подметрика «Уязвимые зависимости»
  с весом 20%: уязвимые пакеты по SCA AppSec против графа зависимостей из `package-lock.json`
  / `npm-shrinkwrap.json` (v2/v3) или `pnpm-lock.yaml` (v6+); транзитивная уязвимость весит
  половину прямой, пакет, не найденный в графе, – как прямая. Взвешенная сумма считается на
  репозиторий, не на строки кода: 0 дает 100, одна прямая критичная (8) – 70, от 60 – 0.
  Остальные веса категории уменьшены пропорционально (40%, 24%, 16%), поэтому без
  lock-файла или без списка пакетов SCA подметрика вне расчета и балл не меняется. Если находки
  AppSec взяты из прошлого анализа, граф текущего не сопоставляется. Потолки не меняются. Совет «Обновите уязвимые зависимости»
  называет прямые зависимости и через какую прямую пришла транзитивная. HealthCraft Index,
  места и рейтинг не меняются: данных AppSec в индексе нет.
- `4.5.0-hci`, сборщик 6 (18.10.2026): разделы установки, сборки и тестов в README находятся
  по любой форме слова в заголовке («Как запустить», «Installation», «Test», «Тестирование»),
  в том числе в заголовках, подчеркнутых строкой `===` или `---`. Формула не меняется,
  репозитории пересобираются ночной волной.
- `4.5.0-hci`, сборщик 5 (28.09.2026): открытая находка AppSec с критичностью `CRITICAL`
  ограничивает Repo Health Score значением 69 – верхом зоны «требует внимания». Утекший
  секрет по-прежнему ограничивает его значением 49, действует меньший потолок. HealthCraft
  Index, места и рейтинг не меняются: данных AppSec в индексе нет.
- `4.4.0-hci`, сборщик 5 (26.09.2026): справочные показатели без веса – стабильность CI в
  динамике, динамика создания и закрытия задач, ревью запросов на слияние и узкие места, карта
  владельцев файлов. Баллы, индекс, покрытие, места и рекомендации не меняются.
- `4.3.1-hci`, сборщик 4 (26.09.2026): пометки техдолга считаются только в коде вне тестов;
  у репозитория без кода Состояние кода получает 0 с причиной вместо «нет данных»;
  рекомендации с нулевым эффектом не выводятся.
- `4.3.0-hci`, сборщик 3 (24.09.2026): тесты как бонус, сжатие балла для малого кода и малой
  выборки задач, потолки Безопасности, CI без видимых запусков – «нет данных».
