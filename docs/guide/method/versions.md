# Версии модели и пересчет

У каждой оценки записана версия модели – набора формул, весов и порогов, по которому оценка посчитана. Сейчас действует модель `4.4.0-hci`. Когда модель меняется, HealthCraft пересчитывает прошлые оценки по сохраненным фактам, поэтому все точки в истории оценки посчитаны одной моделью и сравнимы.

## Где видна версия

- В рейтинге: нажмите [[Как считается?]], в разделе [[Расчет]] – строка [[Версия методики]].
- На карточке репозитория: правая панель, раздел [[Реквизиты]] – номер анализа и [[Версия методики]].
- В отчете Markdown и PDF: приложение «Г. Версия методики, номер анализа и режим запуска».
- В публичном API: поле `modelVersion` в ответе `/api/v1/repos/<org>/<repo>`.

## Воспроизводимость {#vosproizvodimost}

Оценку считает код, без случайности и без языковой модели. Одинаковые факты на одну и ту же дату анализа всегда дают одинаковую оценку. AI-обзор оценку не меняет.

Что для этого сделано:

- Все числа модели – веса, пороги, потолки – записаны в коде и не подстраиваются под данные. Их список – на страницах [Два показателя и формула](scores.md) и [Категории и метрики](metrics.md).
- Подметрики со сроками, например свежесть коммита или предложения изменений за 90 дней, считаются от момента анализа, а не от текущей даты. Анализ годовой давности при пересчете получает ту же свежесть, что в день анализа.
- Оценка округляется одним правилом на всех экранах, в отчете, бейдже и API.
- Публичный API отдает баллы категорий без округления. По ним расчет можно повторить вручную – см. [Пример расчета](scores.md#primer).
- Каждый факт виден на карточке: у рекомендации откройте плашку показателя и нажмите [[Исходные данные]].

## Когда меняется версия {#smena-versii}

Новая версия модели выходит при любой правке, которая меняет смысл балла. Это правка формулы, веса, порога, признака робота или правила, по которому факт относится к группе. Номер версии меняется и тогда, когда в оценке появляются новые справочные показатели.

Последние версии:

| Версия | Что изменилось |
|---|---|
| `4.4.0-hci` | Справочные показатели без веса: стабильность CI в динамике, динамика бэклога, поток задач, показатели ревью предложений изменений, карта владельцев файлов. Баллы, оценки и места не изменились. |
| `4.3.1-hci` | Пометки TODO считаются только в коде вне тестов. Репозиторий без кода получает по категории «Состояние кода» 0 вместо «нет данных». Рекомендации без эффекта не показываются. |
| `4.3.0-hci` | Тесты стали бонусом. Малый код и малая выборка задач сжимаются. Появились потолки категории «Безопасность». CI без видимых запусков получает «нет данных». |

Отдельно от модели меняется версия сборщика – правил, по которым анализ собирает факты. Сейчас действует сборщик 5. Новый сборщик собирает новые факты, поэтому пересчет тут не поможет: нужен новый анализ. Репозитории, собранные прежним сборщиком, HealthCraft ставит на повторный анализ в суточную волну: по умолчанию до 5000 за волну, начиная с репозиториев с большим числом реакций. До нового анализа новые показатели на карточке подписаны [[появится после следующего анализа]].

## Пересчет истории {#pereschet}

HealthCraft хранит факты каждого анализа: исходный код не хранится, но числа и признаки, из которых складывается оценка, остаются в базе. Поэтому смена модели не требует повторных анализов: новые оценки считаются по уже собранным фактам, без обращений к SourceCraft.

Как проходит пересчет:

1. При запуске сервис сравнивает версию модели в коде с версиями сохраненных оценок.
2. Если есть оценки прежней версии без пары в новой, сервис запускает пересчет в фоне. Сайт в это время работает.
3. Анализы пересчитываются порциями по 50, от старых к новым. Для каждого заново считаются оценка, рекомендации и признак участия в рейтинге.
4. После каждой порции сервис запоминает, докуда дошел. Если сервис перезапустили или пересчет остановился, его продолжит фоновый обработчик с этого же места.

Оценки прежней версии не перезаписываются: новые оценки сохраняются рядом с ними под новым номером версии.

Ход пересчета виден в ответе `https://health-craft.ru/api/health`, в поле `rescore`:

```json
{
  "rescore": { "running": true, "done": 21400, "total": 48600, "error": null }
}
```

Здесь `done` – номер последнего пересчитанного анализа, `total` – номер последнего анализа в базе. Когда `done` равно `total`, а `running` – `false`, пересчет закончен.

## Что видит пользователь {#chto-vidit}

- После выхода новой версии оценка репозитория может измениться без нового анализа: факты те же, модель новая.
- Рейтинг, карточка, сравнение и API показывают только оценки текущей версии. Пока идет пересчет, в рейтинге участвуют только уже пересчитанные анализы, а оценки двух версий не смешиваются. Анализы пересчитываются от старых к новым, поэтому в это время у части репозиториев может быть видна оценка более раннего анализа.
- В разделе [[История оценки]] на карточке все точки посчитаны текущей версией. Разница между точками – следствие новых фактов и прошедшего времени, а не смены модели.
- Рекомендации и их ожидаемый эффект тоже пересчитываются новой моделью.
