# Источники данных и приватность

HealthCraft берет факты из 4 источников: каталога открытых репозиториев, git-клона репозитория, REST API SourceCraft и AppSec API SourceCraft. Оценку по фактам считает код. Находки об уязвимостях HealthCraft берет только из AppSec SourceCraft, поэтому Безопасность оценивается по тем же находкам, что видит команда, без собственных правил сервиса. Исходный код HealthCraft не хранит, а закрытые данные показывает только тем, у кого есть к ним доступ в SourceCraft.

## Что откуда берется {#svodka}

| Источник | Что берем | Где используется |
|---|---|---|
| Каталог открытых репозиториев | список репозиториев, название, язык, оценку реакций, дату последнего изменения | рейтинг и расписание анализов, в оценку не входит |
| Git-клон | историю коммитов, файлы в корне, README, LICENSE, CONTRIBUTING, CODEOWNERS, файлы `.sourcecraft/`, строки кода, файлы тестов, пометки TODO и FIXME | Документация, Активность, Состояние кода, CI/CD (конфигурация) |
| REST API SourceCraft | задачи и первые ответы в них, участников, релизы, предложения изменений, запуски CI | Задачи, Активность, CI/CD |
| AppSec API SourceCraft | открытые находки последней проверки по критичности, утекшие секреты, долю исправленных | Безопасность |

Углубленную аналитику – bus factor, ревью предложений изменений, поток задач, карту владельцев файлов и стабильность CI – карточка показывает справочно, без веса в оценке; подробнее – в разделе [Справочные показатели](../method/metrics.md#spravochnye). Как каждый факт превращается в балл – на странице [Категории и метрики](../method/metrics.md).

## Git-клон

HealthCraft клонирует репозиторий с `https://git.sourcecraft.dev/<org>/<repo>.git` без рабочей копии во временный каталог. Плановый анализ открытого репозитория клонирует его анонимно, анализ по вашей заявке – с вашим персональным токеном SourceCraft, поэтому доступны и приватные репозитории.

Из клона извлекаются история коммитов основной ветки, файлы в корне и в `.sourcecraft/`, разделы README, строки кода, файлы тестов, пометки TODO и FIXME с их возрастом и справочно – карта владельцев файлов. Правила подсчета описаны на странице [Категории и метрики](../method/metrics.md).

Клон дает факты, которых нет в REST API. Только по содержимому файлов видно, сколько в проекте кода, какая плотность пометок TODO и как давно они появились, есть ли тесты и о чем рассказывает README. История коммитов с датами авторов показывает, кто и как часто работает над проектом, отделяет людей от роботов и сгенерированных пачек и дает карту владельцев файлов. Поэтому Документация и Состояние кода оцениваются по содержимому репозитория, а не по его описанию.

## REST API SourceCraft

REST API доступен по адресу `https://api.sourcecraft.tech`, его спецификация лежит в репозитории HealthCraft в файле `docs/api-spec/sourcecraft.swagger.json`. Плановый анализ обращается к API с токеном сервиса (`SOURCECRAFT_TOKEN`), анализ по вашей заявке – с вашим персональным токеном.

| Метод | Что берем |
|---|---|
| `GET /repos` | каталог открытых репозиториев, по 100 записей на страницу |
| `GET /repos/{org}/{repo}` | название, язык, реакции, ответвления, видимость, дату изменения, id для AppSec |
| `GET /repos/{org}/{repo}/issues` | задачи в статусах `open`, `in_progress`, `closed` |
| `GET /repos/{org}/{repo}/issues/{issue}/comments` | время первого ответа в 50 самых свежих открытых задачах |
| `GET /repos/{org}/{repo}/contributors` | число участников |
| `GET /repos/{org}/{repo}/releases` | даты опубликованных релизов |
| `GET /repos/{org}/{repo}/pulls` | даты и статусы предложений изменений |
| `GET /repos/{org}/{repo}/pulls/{pull}/comments`, `…/reviewers` | ревью 10 последних предложений изменений, справочно |
| `GET /repos/{org}/{repo}/cicd/runs` | статусы, даты и длительность запусков CI |
| `GET /user`, `GET /me/repos` | проверку персонального токена и список ваших репозиториев для [[repos:Мои репозитории]], окна добавления в [[favorites:Избранное]] и кнопки анализа у репозиториев ваших организаций; список хранится 10 минут, ссылка [[Обновить список]] под заголовком раздела читает его заново; карточка репозитория проверяет права при каждом открытии |

Списки для анализа HealthCraft читает не дальше 5 страниц по 100 записей. Каталог читается до 1000 страниц, а список ваших репозиториев `GET /me/repos` – до 40 страниц и не больше 200 репозиториев. Если список задач, участников или предложений изменений длиннее, в факте остается пометка. Запуски CI – закрытые данные репозитория, их видят только его участники, поэтому без токена участника этот факт получает «нет данных».

## AppSec API SourceCraft

AppSec API доступен по адресу `https://appsec.sourcecraft.tech`, спецификация – в файле `docs/api-spec/appsec.openapi.yaml`. HealthCraft обращается к нему только с персональным токеном участника: при анализе и при проверке прав зрителя на Безопасность. При анализе запросы идут так:

1. `GET /repos/{org}/{repo}` в REST API возвращает id репозитория.
2. `GET /v1/scans/latest` возвращает последнюю проверку AppSec. Она должна быть завершенной и актуальной.
3. `GET /v1/defect-groups` возвращает открытые группы находок этой проверки в статусах `OPEN`, `TRIAGE_IN_PROGRESS`, `TRIAGED_TP` и `FIX_IN_PROGRESS`. По ним HealthCraft считает число групп по критичности и критичные секреты (`type=SECRETS`).

Сохраняются только счетчики и id групп: без кода, путей и значений секретов. Если проверки нет, она не закончилась или ответ пришел не целиком, Безопасность получает «нет данных», а не «уязвимостей нет». Подробнее – на странице [Обработка отсутствующих данных](../method/no-data.md).

## Бюджеты и повторы запросов {#byudzhety}

На 1 анализ HealthCraft делает не больше 1000 запросов к REST API (`SCAN_BUDGET`) и не больше 40 запросов к AppSec API. Ответа REST API он ждет до 10 с, AppSec API – до 15 с. Между запросами с одним токеном к REST API выдерживается пауза 50 мс, между запросами к AppSec API – 100 мс. Обход каталога читает до 1000 страниц, а бюджеты клона описаны в разделе [Крупные репозитории](../ops/scaling.md#krupnye).

На ответ 429 или 503 REST API HealthCraft повторяет запрос до 3 раз. Пауза перед повтором берется из заголовка `Retry-After`, а без него составляет 1, 2 и 4 с. Если SourceCraft просит ждать дольше 30 с, повтора нет. Повторы к REST API бюджет не расходуют. Запросы, ответ на которые вы ждете на экране, – проверка токена и прав, список ваших репозиториев – повторяются 1 раз и ждут повтора не дольше 2 с. К AppSec API при сбое сети, ответе 429 или 5xx HealthCraft делает 1 повтор, и он входит в бюджет 40 запросов.

## Доступ и приватность {#privatnost}

### Что хранится

Репозиторий клонируется во временный каталог только на время анализа и удаляется при любом исходе. Клоны, оставшиеся после аварийной остановки процесса, удаляет плановая уборка раз в час. Код открытых репозиториев HealthCraft читает только для подсчета фактов, как любой посетитель SourceCraft, и не публикует его. Фрагменты кода видит только языковая модель во время AI-обзора, причем файлы секретов она не открывает; подробнее – на странице [Внешние сервисы и AI](ai.md).

| Данные | Что хранится в базе |
|---|---|
| Факты анализа | счетчики, признаки наличия файлов, имена файлов в корне и в `.sourcecraft/`, даты, короткие тексты ошибок CI, агрегаты AppSec без кода и путей |
| История коммитов | хеш, имя и адрес почты автора и коммитера, даты – для расчета активности и признаков роботов |
| Оценки и рекомендации | баллы категорий, HealthCraft Index, рекомендации с версией модели |
| AI-тексты | проверенные тексты AI-обзоров и проверок активности, причины, по которым текст не сформировался |
| Пользователи | идентификатор Яндекс ID, логин, имя и аватар из профиля; отпечаток пароля снятия лимитов AI, если пользователь его ввел, а не сам пароль |
| Избранное | список репозиториев пользователя, даты добавления и последней проверки прав |
| Сессии | только хеш случайного токена из cookie, срок – 7 дней |
| Персональные токены SourceCraft | только в зашифрованном виде |
| Снимки рейтинга | место и HealthCraft Index каждого репозитория на дату, хранятся 35 дней |
| Очередь заявок | заявки на анализ и AI, завершенные удаляются через 30 дней |

Историю коммитов HealthCraft не показывает: в карточке, отчете и API видны только число коммитов и даты первого и последнего, а в карте владельцев файлов – имена авторов без почты. Токен Яндекс ID сервис не сохраняет: он нужен только для чтения профиля при входе.

### Персональный токен SourceCraft

Токен шифруется алгоритмом AES-256-GCM. Ключ выводится из секрета сервера `APP_SECRET` и в базе не лежит. Токен расшифровывается только в момент запроса к SourceCraft, не возвращается в браузер и не пишется в журналы. Для клона приватного репозитория git получает токен в заголовке HTTP, а не в командной строке.

Удалить или заменить токен можно в любой момент: откройте [[settings:Настройки]] и нажмите [[Удалить]] или [[Заменить]]. Если оператор сервиса сменил `APP_SECRET`, сохраненный токен перестает расшифровываться, и в [[settings:Настройки]] появится отметка [[label-warning:Нужно сохранить заново]].

### Закрытые данные – только с правами {#zakrytye-dannye}

Закрытыми HealthCraft считает результаты запусков CI, находки AppSec и сами приватные и внутренние репозитории. Права HealthCraft проверяет, читая эти данные вашим токеном: запуски CI, последнюю проверку AppSec или описание репозитория. Результат проверки HealthCraft помнит 15 мин, а если SourceCraft ответил сбоем – 60 с. После замены или удаления токена права проверяются заново.

- Данные CI и AppSec, собранные токеном одного участника, сохраняются вместе с анализом. Другой зритель увидит их, только если его токен дает доступ к тем же данным.
- Без входа или без токена на карточке видны HealthCraft Index и 4 открытые категории, CI/CD и Безопасность закрыты.
- Карточка приватного репозитория без прав отвечает так же, как для несуществующего: «не найден». Отчеты и сравнение проходят ту же проверку.
- В рейтинг попадают только открытые репозитории каталога. Репозиторий, видимость которого SourceCraft еще не подтвердил, считается приватным.

### Публичный API

Публичный API и бейдж работают только для открытых репозиториев рейтинга. На запрос о приватном, выведенном из рейтинга и несуществующем репозитории HealthCraft отвечает одинаково – 404. Ответ содержит HealthCraft Index и баллы 4 открытых категорий, без фактов, AI-текстов и истории коммитов. Подробнее – на странице [Бейдж и публичный API](../guide/badge-api.md).
