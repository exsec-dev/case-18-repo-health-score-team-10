# Соответствие ТЗ

Страница сопоставляет требования технического задания с возможностями HealthCraft и страницами документации. В первой колонке – пункт ТЗ и краткий пересказ требования.

## Сервис оценки здоровья

| Требование ТЗ | Как сделано в HealthCraft | Страница |
|---|---|---|
| 3.1. Открытые репозитории SourceCraft, без импорта с других платформ | Каталог открытых репозиториев SourceCraft, git-клон, REST API и AppSec API SourceCraft; импорта нет | [Источники данных](data/sources.md) |
| 3.1. Документация: README, лицензия, запуск, сборка и тесты, структура, CONTRIBUTING и CODEOWNERS | README – наличие, размер и разделы «Установка», «Сборка», «Тесты»; лицензия, CONTRIBUTING, CODEOWNERS; структура – подметрика «Порядок в корне репозитория» | [Документация](method/metrics.md#documentation) |
| 3.1. CI/CD: наличие, статусы запусков, доля успехов, длительность, стабильность в динамике | `ci.yaml` с командами, доля успешных запусков с весом свежести, медиана длительности; стабильность в динамике – справочно | [CI/CD](method/metrics.md#cicd) |
| 3.1. Безопасность по AppSec: SAST, SCA, секреты, критичность, статус исправления | Плотность открытых находок по критичности, доля закрытых, критичные утечки секретов, потолки категории; разбивка по видам проверок; собственного сканирования нет | [Безопасность](method/metrics.md#security) |
| 3.1. Активность: коммиты, последняя активность, участники, запросы на слияние, релизы, динамика | Свежесть и частота коммитов людей, число авторов, предложения изменений за 90 дней, релизы за 12 месяцев; коммиты за 90 дней и за год – справочно | [Активность](method/metrics.md#activity) |
| 3.1. Задачи: открытые и закрытые, динамика, зависшие, первый ответ, время закрытия | Доля решенных, доля зависших, медиана закрытия, время до первого ответа; динамика бэклога и поток задач – справочно | [Задачи](method/metrics.md#issues) |
| 3.1. Состояние кода: TODO и FIXME, их число и давность, технический долг | Плотность пометок на 1000 строк, доля старше 180 дней по `git blame`, доля файлов тестов, порядок в корне | [Состояние кода](method/metrics.md#code) |
| 3.2. Оценка 0-100 с детализацией по категориям | Repo Health Score по 6 категориям с весами 15-20 и публичный HealthCraft Index по 4 открытым категориям; детализация по категориям и подметрикам на карточке | [Два показателя и формула](method/scores.md) |
| 3.2. Воспроизводимость | Код без случайности и языковой модели, версия модели у каждой оценки, пересчет истории из сохраненных фактов | [Воспроизводимость](method/versions.md#vosproizvodimost) |
| 3.2. Объяснимость и опора на факты | Формула, веса и пороги опубликованы; от каждой рекомендации можно перейти к факту и исходным данным | [Категории и метрики](method/metrics.md) |
| 3.2. «Нет данных» вместо плохого результата | 3 состояния факта; категория без данных выпадает из формулы; при покрытии ниже 40% оценки нет | [Когда данных нет](method/no-data.md) |
| 3.2. Исключение категории описано вместе с влиянием на оценку | Рейтинг по HealthCraft Index без CI/CD и Безопасности: эти данные видны только участникам; веса пересчитаны на 100 | [Почему рейтинг по HealthCraft Index](method/scores.md#pochemu-index) |
| 3.2. Логичное поведение на контрольных сценариях | 6 проблем, исправления и «нет данных» на одном репозитории с пересчитанными числами | [Как меняется оценка](method/scenarios.md) |
| 3.3. Рекомендации: проблема, причина, факты, действие, приоритет, влияние на оценку | Действие, причина, плашка показателя с фактом, номер по приоритету, ожидаемый эффект пересчетом модели, заготовки файлов | [Рекомендации](guide/recommendations.md) |
| 3.4. Страница анализа: название и ссылка, оценка, категории, сильные и слабые стороны, расчет, рекомендации, «нет данных», дата анализа, выгрузка | Карточка `/repo/<org>/<repo>` со всеми этими блоками и кнопкой [[download:Отчет]] | [Карточка репозитория](guide/card.md) |
