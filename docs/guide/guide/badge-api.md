# Бейдж и публичный API

HealthCraft отдает HealthCraft Index открытого репозитория без входа: JSON для интеграций и SVG-бейдж для README. Оба маршрута работают только для открытых репозиториев из рейтинга.

## Маршруты

Адреса – относительно `https://health-craft.ru`.

| Запрос | Ответ |
|---|---|
| `GET /api/v1/repos/<org>/<repo>` | JSON с индексом и баллами 4 категорий |
| `GET /api/v1/repos/<org>/<repo>/badge.svg` | бейдж с индексом |
| `GET /api/v1/repos/<org>/<repo>/badge.svg?style=rank` | бейдж с индексом и лигой места |

Для внешних интеграций предназначен только `/api/v1`. Остальные адреса `/api/*` обслуживают интерфейс: их ответ зависит от прав зрителя и может меняться.

## Пример ответа {#primer}

Чтобы получить оценку репозитория, выполните:

```bash
curl https://health-craft.ru/api/v1/repos/<org>/<repo>
```

Ответ для выдуманного репозитория `example/tasktracker`, например:

```json
{
  "org": "example",
  "repo": "tasktracker",
  "title": "Task Tracker",
  "language": "TypeScript",
  "likes": 14,
  "healthcraftIndex": 61,
  "indexCoverage": 1,
  "categories": {
    "documentation": 47.95,
    "activity": 69.40816326530612,
    "issues": 41.5,
    "code": 79.72
  },
  "modelVersion": "4.4.0-hci",
  "scannedAt": "2026-09-20T03:14:08.512Z",
  "headSha": "4f2a9c1e7b03d58a6e91f0c2b7d4a3e8f5c6019b"
}
```

| Поле | Что значит |
|---|---|
| `org`, `repo`, `title`, `language`, `likes` | имя, название, язык и число реакций в SourceCraft |
| `healthcraftIndex` | HealthCraft Index, целое 0-100; `null` – оценки нет |
| `indexCoverage` | покрытие: доля веса категорий с данными, от 0 до 1 |
| `categories` | баллы Документации, Активности, Задач и Состояния кода без округления; `null` – нет данных |
| `modelVersion` | версия модели оценки |
| `scannedAt` | время завершения анализа, по которому посчитана оценка |
| `headSha` | коммит, который анализировался |

Индекс повторяется по баллам: (47,95 × 23 + 69,41 × 23 + 41,5 × 23 + 79,72 × 31) / 100 = 61,25 → 61. Веса и округление – на странице [Два показателя и формула](../method/scores.md).

Индекса нет в 2 случаях:

- данных не хватило: `healthcraftIndex` – `null`, `indexCoverage` меньше 0,4, в `categories` балл есть не больше чем у 1 категории;
- репозиторий в рейтинге, но еще не анализировался: `indexCoverage` – 0, `categories` пуст, `scannedAt` – `null`.

Repo Health Score, CI/CD и Безопасность публичный API не отдает: эти данные видны только участникам репозитория.

## Бейдж для README

Чтобы получить код бейджа:

1. Откройте карточку открытого репозитория с оценкой. Бейдж есть у любого такого репозитория, не только у своего.
2. Нажмите [[badge:Бейдж для README]]. На мобильных устройствах кнопка – в меню [[more:Еще действия]].
3. Если у репозитория есть лига, выберите [[Только индекс]] или [[Индекс и место]].
4. Под подписью [[Markdown]] нажмите кнопку копирования [[Скопировать]] справа в поле с кодом.
5. Вставьте код в README.

Ссылка [[Данные в JSON]] под полем открывает ответ публичного API для этого репозитория.

Код выглядит так, картинка ведет на карточку репозитория:

```text
[![HealthCraft Index](https://health-craft.ru/api/v1/repos/<org>/<repo>/badge.svg)](https://health-craft.ru/repo/<org>/<repo>)
```

Цвет числа – по зоне: зеленый для 70-100, желтый для 40-69, красный для 0-39. Без оценки бейдж показывает `n/a` серым. Вариант `style=rank` добавляет сегмент лиги: [[league-gold:ТОП-10]], [[league-silver:ТОП-100]] или [[league-bronze:ТОП-1000]]. У репозитория без лиги он совпадает с обычным бейджем. Другое значение `style` – ответ 400.

## Кэш и лимиты

- Ответ 200 кэшируется на 5 мин (`Cache-Control: public, max-age=300`). После нового анализа бейдж может показывать прежнее число до 5 мин.
- С 1 IP-адреса – не больше 120 запросов в минуту, общих для JSON и бейджа. Сверх лимита – ответ 429 с кодом `rate_limited` и заголовком `Retry-After: 60`.
- Заголовков CORS маршруты не отдают. Запрашивайте JSON со своего сервера или из CI, а не из браузерного кода на другом сайте.

## Приватность

Приватный, внутренний, выведенный из рейтинга и несуществующий репозиторий дают одинаковый ответ 404. По ответу нельзя узнать, существует ли закрытый репозиторий. В JSON и бейдже нет фактов, рекомендаций, текстов модели и данных закрытых категорий. Подробнее – на странице [Доступ и приватность](../data/privacy.md).
